## ۱. مقدمه و فلسفه طراحی
**پروان (ParvanLang)** یک زبان برنامه‌نویسی مدرن، سریع، چندپارادایمی و کاملاً دوزبانه (فارسی و انگلیسی) است که هسته آن با زبان قدرتمند Rust توسعه یافته است. پروان از مدیریت حافظه امن بدون Garbage Collector سنتی بهره می‌برد و از دو موتور اجرای همزمان پشتیبانی می‌کند:
- **مفسر درختی (AST Tree-Walking Interpreter):** ایده‌آل برای اسکریپتینگ سریع و خطایابی آنی.
- **کامپایلر بایت‌کد و ماشین مجازی استک (Stack Bytecode VM):** شتاب‌یافته برای محاسبات سنگین و سیستم‌های مقیاس‌پذیر.

## ۲. متغیرها و انواع داده
در پروان کلمات کلیدی به دو زبان فارسی و انگلیسی کاملاً متقارن هستند:

```javascript
// انگلیسی
let score = 100;
const PI = 3.14159;
let active = true;
let name = "پروان";
let list = [10, 20, 30];
let map = {"key": "value"};

// فارسی
متغیر امتیاز = ۱۰۰;
ثابت پی = ۳.۱۴۱۵۹;
متغیر فعال = درست;
متغیر نام = "پروان";
متغیر لیست = [۱۰, ۲۰, ۳۰];
```

### درون‌یابی رشته‌ها (f-strings):
```javascript
let user = "علی";
let age = 22;
println("کاربر: {user}، سن سال بعد: {age + 1}");
```

## ۳. ساختارهای کنترلی و حلقه‌ها

### شرط‌ها (`if / else` یا `اگر / وگرنه`):
```javascript
if score >= 50 {
    println("قبول");
} else {
    println("مردود");
}
```

### حلقه‌ها (`for` و `while`):
```javascript
// حلقه با شمارش افزایشی
for i in [1, 2, 3, 4, 5] {
    println(i);
}

// حلقه دیکشنری
for [k, v] in {"status": "ok", "code": 200} {
    println(k + " -> " + v);
}
```

## ۴. توابع، لامبداها و پایپ‌لاین

### توابع استاندارد:
```javascript
fn add(a, b) {
    return a + b;
}

تابع ضرب(الف, ب) {
    بازگردان الف * ب;
}
```

### توابع پیکانی کوتاه (Arrow Lambdas):
```javascript
let square = (x) -> x * x;
println(square(5)); // 25
```

### عملگر خط لوله (Pipeline `|>`):
```javascript
let double = (n) -> n * 2;
let inc = (n) -> n + 1;

let result = 10 |> double |> inc; // (10 * 2) + 1 = 21
```

## ۵. ماژولار بودن و وارد کردن فایل‌ها
در نسخه ۲.۷ می‌توانید فایل‌ها را به شکل ماژولار با نام مستعار وارد کنید تا متغیرها تداخل نکنند:

```javascript
// math_tools.prv
let add = fn(a, b) { return a + b; };
let MAGIC = 42;

// main.prv
import "math_tools.prv" as math;
println(math.add(10, math.MAGIC)); // 52

// معادل فارسی:
وارد_کردن "math_tools.prv" به_عنوان ریاضی;
چاپ(ریاضی.add(۱۰, ۲۰));
```

## ۶. شیءگرایی و ساختارها (`struct`)
تعریف ساختارها، فیلدها و متدها با اتصال خودکار اشاره‌گر `self` یا `این`:

```javascript
struct Developer {
    name, role,
    fn info() {
        return self.name + " (" + self.role + ")";
    }
}

let dev = Developer("علی حسنی‌فرد", "معمار سیستم");
println(dev.info());
```

## ۷. شمارنده‌ها و تطبیق الگو (`enum` & `match`)
برای مدیریت تمیز حالت‌ها بدون نیاز به `if`های تودرتو:

```javascript
enum State {
    Running,
    Stopped,
    Error
}

let handle_state = fn(s) {
    match s {
        State.Running => { return "سیستم فعال است"; }
        State.Stopped => { return "سیستم متوقف شد"; }
        default => { return "وضعیت نامشخص"; }
    }
};

println(handle_state(State.Running));
```

## ۸. ماشین مجازی و باینری‌ساز مستقل

### اجرای کد روی ماشین مجازی بایت‌کد:
```bash
parvan --vm script.prv
```

### کامپایل به اگزه تک‌فایل بدون نیاز به نصب پروان:
```bash
parvan build main.prv -o MyApp.exe
```

### تولید باندل لینوکس:
```bash
parvan build main.prv -o MyLinuxApp -t linux
```

## ۹. کتابخانه استاندارد جامع (Stdlib)
- **شبکه و وب:** `http_get`, `http_post`, `http_put`, `http_delete`, `http_listen`
- **پایگاه داده توکار:** `db_open`, `db_exec`, `db_query`
- **تقویم و زمان:** `to_jalali(gy, gm, gd)`, `now()`
- **ریاضی و مثلثات:** `sin`, `cos`, `tan`, `pow`, `log`, `min`, `max`, `random`
- **رمزنگاری و امنیت:** `sha256`, `md5`, `base64_encode`, `base64_decode`
- **فایل‌سیستم:** `mkdir`, `remove_file`, `list_dir`, `file_exists`
- **فرمت داده:** `json_parse`, `json_stringify`
