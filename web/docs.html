زبان برنامه‌نویسی پروان (ParvanLang)

زبان برنامه‌نویسی فوق‌العاده سریع، دوزبانه (فارسی و انگلیسی)، چندپارادایمی و مستقل توسعه‌یافته با زبان قدرتمند Rust همراه با ماشین مجازی بایت‌کد و پایگاه داده توکار.

شروع یادگیری مخزن در گیت‌هاب

⚡ ماشین مجازی بایت‌کد (Stack VM)

سرعت مافوق صوت با کامپایل مستقیم کدهای AST به اوپ‌کدهای بایت‌کد و اجرای شتاب‌یافته روی استک ماشین مجازی.

parvan --vm script.prv

🏛️ شیءگرایی و ساختارها (Structs & Methods)

تعریف ساختارها با فیلدها و متدها، و اتصال خودکار اشاره‌گر self یا این به دو زبان فارسی و انگلیسی.

struct User {
    name, score,
    fn info() { return self.name; }
}

🗄️ پایگاه داده و میکروسرور وب توکار

توابع بومی db_open، db_exec و شنود درخواست‌های وب شبکه با http_listen بدون نیاز به کتابخانه خارجی.

let db = db_open("data.db");
db_exec(db, "CREATE TABLE users");

📦 بیلد اجرایی مستقل (Standalone Binary)

امکان ساخت فایل .exe مستقل از کدهای منبع پروان بدون نیاز به نصب هیچ مفسری روی سیستم مشتری.

parvan build main.prv -o app.exe
