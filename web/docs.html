مهندسی زبان مدرن؛
سرعت کد ماشین بومی، ظرافت دوزبانه.

زبان برنامه‌نویسی پیشرفته چندپارادایمی مجهز به کامپایل به کد ماشین واقعی (AOT C99 با GCC -O3)، فریم‌ورک وب‌سرور چندترده، سیستم تحلیل استاتیک انواع داده، رجیستری ابری PPM، و تست‌رانر درون‌زبانی.

پلی‌گراند آنلاین (Playground) ⚡ مخزن گیت‌هاب
app.prv — ParvanLang v2.6.0
// ساختار شیءگرا، متدها و تقویم بومی هجری شمسی
struct Developer {
  name, role, skills,
  fn introduce() {
    let today = to_jalali(2026, 10, 23);
    return "توسعه‌دهنده: {self.name} | تاریخ: {today}";
  }
}

let dev = Developer("علی حسنی‌فرد", "معمار سیستم", ["Rust", "Compiler"]);
println(dev.introduce());

شش ستون قدرت اکوسیستم پروان نسخه ۴

طراحی‌شده با دقت صنعتی، کامپایل به کد ماشین واقعی و معماری مافوق صوت با زبان راست

⚡

کامپایل به کد ماشین واقعی (AOT Native C99)

ترجمه مستقیم به C99 فوق‌بهینه و کامپایل به کدهای باینری بومی x86_64 با فراخوانی خودکار کامپایلر GCC و سطح بهینه‌سازی -O3.

$ parvan build app.prv -o app.exe -t native
🌐

فریم‌ورک وب‌سرور چندترده (Web Server Engine)

توسعه میکروسرویس‌ها و APIهای با کارایی بالا با روتر مدرن، پارس خودکار هدرها، بدنه و کوئری، و بازگردانی خودکار JSON استاندارد.

http_server_route(srv, "GET", "/api", handler);
🔬

تحلیل استاتیک و بررسی انواع (Type Checker)

کشف پیش‌دستانه خطاهای عدم تطابق نوع داده، متغیرهای تعریف‌نشده و عملگرهای نامعتبر قبل از اجرای برنامه در محیط پروداکشن.

$ parvan check source.prv
📦

پکیج منیجر ابری PPM (Package Registry)

مدیریت وابستگی‌ها و بسته‌بندی کتابخانه‌ها در قالب آرشیوهای امن .prvp با کش هوشمند محلی و رجیستری متمرکز.

$ parvan add math_extra
🧹

مدیریت حافظه ایمن از چرخه (Cycle-Safe GC)

سیستم پایش بلادرنگ اشیاء حافظه و پاکسازی پیشرفته ارجاعات متقابل در کلوسرها و متغیرها با تابع توکار gc_collect().

let freed = gc_collect();
🧪

فریم‌ورک تست‌نویسی درون‌زبانی (Test Runner)

تست‌نویسی مستقیم به خود زبان پروان با توابع توکار test و assert و گزارش تفکیکی رنگی و خودکار نتایج آزمون‌ها.

$ parvan test
