## ✨ ویژگی‌های برجسته:
- ⚡ **پیاده‌سازی با Rust:** سرعت و امنیت حافظه بالا بدون وابستگی‌های سنگین.
- 🌐 **پشتیبانی کامل دوزبانه (فارسی و انگلیسی):** امکان نوشتن کدها با کلیدواژه‌های فارسی (`اگر`، `وگرنه`، `تابع`، `متغیر`، `چاپ`، `تلاش`، `خطا`، `وارد_کن`) یا انگلیسی (`if`, `else`, `fn`, `let`, `print`, `try`, `catch`, `import`).
- 🗂️ **دیکشنری‌ها و نگاشت‌های کلید-مقدار (HashMaps & Objects):** پشتیبانی از تعریف آبجکت‌ها (`{ "name": "Ali" }`) و دسترسی با دات (`user.name`) یا براکت (`user["name"]`).
- 🛡️ **مدیریت خطای مدرن (Try / Catch Blocks):** مهار خطاها و جلوگیری از متوقف شدن برنامه بدون کرش.
- 📦 **سیستم ماژولار و ایمپورت فایل‌ها (`import "module.prv"`):** امکان تقسیم پروژه‌های بزرگ به چندین فایل مجزا.
- 🧩 **توابع درجه یک و کلوژرها (First-class Functions & Closures):** امکان پاس دادن توابع به عنوان آرگومان و ساخت Lambdas.
- 🔄 **ساختارهای داده غنی:** پشتیبانی از اعداد صحیح (i64)، اعشاری (f64)، رشته‌ها، بولین، آرایه‌های پویا، دیکشنری‌ها و مقادیر nil.
- 🎛️ **محیط تعاملی زنده نئونی (Cyberpunk REPL):** تست آنی کدها در ترمینال با هایلایت رنگی.
- 📚 **کتابخانه استاندارد جامع (Builtins):**
  - کار با مجموعه‌ها: `len`, `range`, `push`, `pop`, `keys`, `values`, `contains`
  - کار با متن: `split`, `join`, `trim`, `uppercase`, `lowercase`
  - ریاضیات: `abs`, `sqrt`, `to_int`, `to_str`
  - ورودی/خروجی و سیستم: `input`, `time`, `read_file`, `write_file`, `type`
- ✅ **مجموعه تست‌های یکپارچگی (Integration Test Suite):** پوشش کامل تست‌های خودکار واحد و یکپارچه در `tests/`.

---

## 🛠️ نحوه نصب و کامپایل:
```bash
cargo build --release
```

فایل اجرایی در مسیر `target/release/parvan.exe` ساخته خواهد شد.

---

## 💻 اجرای فایل‌های کد:
```bash
parvan examples/fibonacci.prv
parvan examples/persian_demo.prv
parvan examples/higher_order.prv
```

یا اجرای مستقیم REPL:
```bash
parvan
```
