# 🚀 Parvan Programming Language (ParvanLang)

**زبان برنامه‌نویسی مدرن، سریع و دوزبانه پروان، توسعه‌یافته با زبان قدرتمند Rust.**

## ✨ ویژگی‌های برجسته:
- ⚡ **پیاده‌سازی با Rust:** سرعت و امنیت حافظه بالا بدون وابستگی‌های سنگین.
- 🌐 **پشتیبانی کامل دوزبانه (فارسی و انگلیسی):** امکان نوشتن کدها با کلیدواژه‌های فارسی (`اگر`، `وگرنه`، `تابع`، `متغیر`، `چاپ`) یا انگلیسی (`if`, `else`, `fn`, `let`, `print`).
- 🧩 **توابع درجه یک و کلوژرها (First-class Functions & Closures):** امکان پاس دادن توابع به عنوان آرگومان و ساخت Lambdas.
- 🔄 **ساختارهای داده غنی:** پشتیبانی از اعداد صحیح (i64)، اعشاری (f64)، رشته‌ها، بولین، آرایه‌های پویا و اشاره‌گرها.
- 🎛️ **محیط تعاملی زنده نئونی (Cyberpunk REPL):** تست آنی کدها در ترمینال با هایلایت رنگی.
- 📦 **کتابخانه استاندارد توابع (Builtins):** شامل `len`، `range`، `push`، `pop`، `input`، `time`، `abs`، `sqrt` و توابع تبدیل نوع.

---

## 🛠️ نحوه نصب و کامپایل:
```bash
cargo build --release
```

فایل اجرایی در مسیر `target/release/parvan.exe` ساخته خواهد شد.

---

## 💻 اجرای فایل‌های کد:
```bash
parvan examples/fibonacci.prv
parvan examples/persian_demo.prv
parvan examples/higher_order.prv
```

یا اجرای مستقیم REPL:
```bash
parvan
```
